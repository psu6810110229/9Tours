เบื้องหลังทำงานยังไง

ฝั่งหน้าเว็บ (frontend) เขียนด้วย React แล้ว build เป็นไฟล์ static วางไว้บน CDN เว็บเลยเปิดได้เร็วและไม่มีวันหลับ ส่วนฝั่งหลังบ้าน (backend) เขียนด้วย NestJS รันอยู่ใน Docker คุยกับฐานข้อมูล PostgreSQL ที่เก็บทัวร์ การจอง และผู้ใช้ทั้งหมดจริง ๆ

หน้าเว็บกับ API อยู่โดเมนเดียวกัน ล็อกอินแล้วคุกกี้เลยทำงานได้ปกติโดยไม่ต้องเปิดช่องพิเศษข้ามโดเมน แล้วมีระบบ ping เข้าไปเตือนเซิร์ฟเวอร์ทุก 5 นาที กันไม่ให้หลับตอนไม่มีคนเข้าใช้ช่วงว่าง

Static site บน CDN Docker web service Managed Postgres โดเมนเดียวกันทั้งเว็บและ API ระบบ ping กันเซิร์ฟเวอร์หลับ
